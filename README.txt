
# Initial usage
- Clone the repo using Visual Studio 2026 Community Edition
- Make sure you have .NET Core 10 available 
- Clean, rebuild solution 
- Run all tests - all results should be green 

# Publishing 
- Make sure you have Docker Desktop installed and running 
- Run the commands from the DockerCommands file - the result should be a running container with our app 

# Postman E2E testing 
- Import into Postman the collection from "FunBooksAndVideos API Tests" file 
- Run all tests with persisted data to be able to visualize the response of each case - all cases should be green
